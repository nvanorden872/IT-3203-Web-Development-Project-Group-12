Search Engine Optimization

Introduction

This site is a project site for IT 3203 Web Development and explores the concept and applications of SEO (Search Engine Optimization). Topics include the history of SEO, its current uses and debates, and an explanation of how it works and why it is important.

Key Terms
SEO Concept Definition
keyword A word or phrase typed into a search engine to locate a webpage.
title tag The title of a webpage that appears in search results and browser tabs.
meta description A short summary that appears under the title of a webpage in search results.
alt text A text-based image description provided to search engines and screen readers.
link A connection between two webpages. Helps users and search engines navigate.
mobile-friendly A webpage which functions properly on mobile devices (often with varying viewport dimensions).
page speed How fast the content of a webpage loads for a given client.
content quality The usefulness, clarity, and originality of information provided by a given webpage.
